# Hosting is fully separate from another project and kept to about $5 a month

This product must share no accounts or infrastructure with another project (no EC2, no AWS account, no Atlas organization). For the MVP the API runs on Railway Hobby as one always-on container. The database is MongoDB Atlas M0 (free), with a nightly `mongodump` because M0 has no backups. Sign-in emails go through Resend's free tier. (Amended: Railway Hobby blocks outbound SMTP ports, so production calls Resend's HTTPS API instead of SMTP; nodemailer over SMTP stays for a local mail catcher in development. Until a sending domain is verified, mail goes from `onboarding@resend.dev` and only reaches the Resend account owner.) We rejected Render's free tier because it sleeps when idle, which breaks sign-in codes and sync. We rejected a new AWS account (SES + Lightsail) because SES starts in a sandbox mode and the account adds upkeep for no MVP benefit. Move to Atlas M10 once real users depend on the data.
