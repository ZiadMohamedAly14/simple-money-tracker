# 09: Categories and Category Budgets

**What to build:** An adult shapes their Categories and sets a Category Budget for each Month. The home screen shows each Category's budget, amount spent and amount remaining.

**Blocked by:** 07 (Personal onboarding and Month overview).

**Status:** ready-for-agent

- [ ] Categories can be added, renamed and reordered. They can be archived (hidden from new Months, kept in history), except Other.
- [ ] A Category Budget can be set per Month. Category Budgets use a deterministic ID worked out from the Account, Month and Category.
- [ ] The per-Category breakdown shows budget, spent and remaining, worked out by shared functions with Seam C tests.
- [ ] Expected Income for the current Month can be edited, and Unallocated updates.
